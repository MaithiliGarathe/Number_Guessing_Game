# 🎯 Number Guessing Game

A simple Python-based Number Guessing Game where the player tries to guess a randomly generated number.

The project was created to practice Python programming fundamentals, random number generation, loops, conditions, and user input.

## 🚀 Features

- 🎲 Generates a random number
- 🔢 Allows the player to enter guesses
- ⬆️ Gives hints when the guess is too low
- ⬇️ Gives hints when the guess is too high
- 🏆 Displays the result when the number is guessed
- 🖥️ Simple command-line interface

## 🛠️ Technologies Used

- Python
- Random module
- Loops
- Conditional statements
- Functions
- User input
